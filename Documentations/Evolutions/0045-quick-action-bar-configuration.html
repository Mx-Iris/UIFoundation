摘要

给 QuickActionBar 加一个存在 bar 上的值类型 QuickActionBar.Configuration，把现在散在 present(…) 九个参数和两个实例属性里的外观与行为设置收进去，并新增一项 cornerRadius，让宿主自定义底板圆角——现在 macOS 26+ 写死 28 pt、更早的系统写死 10 pt。present 只留每次打开才变的三个参数：parentWindow、initialSearchText、didClose。

旧的九参数 present 与 requiredClickCount 标废弃并转发到新 API，rowHeight 早已不起作用、标废弃。所有默认值与现在一致，三个下游 App 不改代码照常编译，只多废弃警告。

已定

  • 配置存在 bar 上（照 SpotlightPanel 的形状），不是每次传进 present。
  • 旧九参数 present 标废弃保留，不删。

公开 API 的变化

提议方案

  1. 新增 QuickActionBar.Configuration，八个字段：placeholderText、searchImage、width、resultsHeight、cornerRadius、showsKeyboardShortcuts、canBecomeMainWindow、requiredClickCount。默认值逐项等于现在 present 的默认值；cornerRadius 默认取 Configuration.defaultCornerRadius（macOS 26+ 为 28，更早为 10）。
  2. QuickActionBar 持有 public var configuration，init() 改为 init(configuration: Configuration = Configuration())，QuickActionBar() 写法不变。
  3. 新 present(parentWindow:initialSearchText:didClose:) 调用时拷一份快照，这次打开只读快照：打开期间改 configuration，下次打开才生效，八个字段一个规则。
  4. 圆角经 Window.setup → PrimaryRoundedView(cornerRadius:) 传下去：26+ 设给玻璃底板，更早设给图层。删掉两处写死值。
  5. 旧 API 保留并标废弃：九参数 present（@_disfavoredOverload，写进配置后转发）、requiredClickCount（转发）、rowHeight（注明不起作用）。
  6. 示例 App、测试、指南、README 改用新 API；演示页加圆角滑块。
非目标（7 条）
  • 不把 browseItems 收进来：它在打开期间可改并带动画，是内容不是配置。
  • 不改三个下游 App 的调用点：只多废弃警告，迁移各自另做。
  • 不改别的写死值：搜索防抖 0.2 s、animationPadding 40、搜索行 56 pt、窗口层级。
  • 不动 DefaultWidth 等大写开头的静态名。
  • 不给 Configuration 加 Equatable / Sendable：NSImage 字段需另外论证，目前无人需要。
  • 不做圆角以外的新外观项（边框、背景色、阴影）。
  • 不保留 requiredClickCount「打开期间改立即生效」：统一成快照规则。

详细设计

QuickActionBar.Configuration 
extension QuickActionBar {
    /// Everything a host can set about how the bar looks and behaves. Read when the bar is presented.
    public struct Configuration {
        public var placeholderText: String
        public var searchImage: NSImage
        public var width: CGFloat?
        public var resultsHeight: CGFloat?
        public var cornerRadius: CGFloat
        public var showsKeyboardShortcuts: Bool
        public var canBecomeMainWindow: Bool
        public var requiredClickCount: RequiredClickCount

        public init(
            placeholderText: String = QuickActionBar.DefaultPlaceholderString,
            searchImage: NSImage = QuickActionBar.DefaultImage,
            width: CGFloat? = nil,
            resultsHeight: CGFloat? = nil,
            cornerRadius: CGFloat = Configuration.defaultCornerRadius,
            showsKeyboardShortcuts: Bool = false,
            canBecomeMainWindow: Bool = true,
            requiredClickCount: RequiredClickCount = .double
        )

        /// 28 points on macOS 26 and later — half of the collapsed bar's 56-point height — and 10 before.
        public static var defaultCornerRadius: CGFloat { get }
    }
}
  • showsKeyboardShortcuts：布尔属性读成断言，照 AppKit 的 showsResizeIndicator。
  • resultsHeight：旧参数 height 实为结果列表高度，换名说清楚。
  • searchImage 不做 Optional：nil 原本只表示「用默认图」，直接把默认图写成默认值。
  • width / resultsHeight 做 Optional：nil 表示「打开那一刻按主屏四分之一算」，即现在的默认行为。
  • cornerRadius 不做 Optional：默认值按系统不同，用 defaultCornerRadius 公开出来，调用方能在它基础上加减。

调研

现状代码、先例与下游调用
  • 圆角写死两处：QuickActionBar+GlassPlatterView.swift:43（28）与 QuickActionBar+PrimaryRoundedView.swift:90（10）。
  • width / height 默认是调用时主屏宽高的四分之一（QuickActionBar.swift:115-116）。
  • height 实为结果列表高度（QuickActionBar+ResultsView.swift:76、QuickActionBar+Window.swift:409）。
  • rowHeight 只在 #available(macOS 10.13, *) 的 else 分支读，本库最低 macOS 14，早已不起作用。
  • requiredClickCount 在点击时才读（QuickActionBar+ResultsView.swift:209）。
  • 26 以前 PrimaryRoundedView 的图层同时是模糊视图的 mask，改它的圆角同时改背景与模糊的形状。
  • 先例：SpotlightPanel.Configuration（存在面板上、init(configuration:)、present 只收每次才变的参数）；0006 把运行时状态与内容留在 Configuration 外。
  • 下游：XCOrganizer QuickOpenPresenter.swift:58、StarLight MainActionBarController.swift:133、RuntimeViewer SidebarRuntimeObjectListViewController.swift:73，三处都传了新 present 没有的参数，只会落到旧方法。

实现时实测的两条

  • present() 落到新方法，已由测试钉住；临时去掉 @_disfavoredOverload 结果相同、不报歧义，所以它是保险而非必需（macOS 27.2、Swift 6.4）。
  • 圆角超过底板高度一半时的观感未查看：需要交互式看界面，用户没有要求；实现把值原样交出去，不做截断。

替代方案

7 条被否的路径
  • 每次传进 present(configuration:)：用户否决；bar 是长寿对象，存在 bar 上与 SpotlightPanel 一致。
  • 只给旧 present 加 cornerRadius:：参数涨到十个，正是要结束的问题。
  • 直接删掉九参数 present：用户否决；破坏性改动要升完整档，三个下游要同批改。
  • cornerRadius: CGFloat?，nil 为默认：调用方读不到默认值是多少。
  • 枚举 CornerStyle：展开后高度在变，「capsule」没有确定含义；目前只有「给个数」一种需求。
  • 把 browseItems 收进来：会失去打开期间修改并带动画的能力。
  • 把 rowHeight 接回去生效：会改变现有自动行高的外观，且无人需要。

影响

  • 源码兼容性：纯新增 + 废弃，不破坏现有调用点。QuickActionBar()、九参数 present、requiredClickCount、rowHeight 照常可用，多废弃警告。
  • ABI：不适用 —— 本库以 SPM 源码分发，使用方每次重新编译。
  • 下游：XCOrganizer、StarLight、RuntimeViewer 照常编译、行为不变；MachOKitUI、PrivateSymbols 未启用该 trait。
  • 文档：QuickActionBar.md、README.md、示例 App 四个文件；根 CLAUDE.md 与 agent 插件 skill 不受影响。
  • 废弃策略：用 message: 而非 renamed:（新写法要拆两步，fix-it 改写不了）；下游迁完后的某个 minor 版本移除，届时单独走提案；本次发 minor。

actionBar.present(parentWindow: window, placeholderText: "Open Quickly", width: 640, height: 320)

// After
